# ELSTELLA & CO. — PROJECT ORIGIN

**Biological Restoration & Therapeutics**  
**Founding scientific initiative:** PROJECT ORIGIN  
**Initial research program:** PROJECT CARDIA  
**Computational demonstrator:** ORIGIN ATLAS

> Elstella investigates how biological systems become dysfunctional and develops computational and therapeutic technologies intended to restore healthy biological function.

## What this repository is

This is the founding research workspace for Elstella. It separates the company's long-term ambition from what has actually been demonstrated today.

- **Elstella Intelligence** is the proposed computational research platform.
- **ORIGIN ATLAS** is its first user-interface demonstrator: a structured workspace for organizing scientific evidence and research hypotheses.
- **PROJECT CARDIA** is the initial research program focused on cardiac fibrosis.
- **PROJECT BIOPATH** is a separate exploratory program on biological transport principles and nature-inspired therapeutic delivery.

## Current status — read this first

This repository is an early research and software prototype. It is **not** a validated scientific discovery, medical device, diagnostic, drug candidate, or therapeutic product. The evidence records are starting references that require full-text review and structured extraction. No claim of novelty, efficacy, or clinical utility is made.

## First execution milestones

1. Verify every source's bibliographic metadata and obtain lawful full-text access.
2. Extract claims, model systems, cell populations, disease contexts, limitations and evidence levels.
3. Have a second reviewer independently check a sample of extractions.
4. Benchmark ORIGIN ATLAS against a conventional literature-review workflow.
5. Ask qualified cardiovascular researchers whether the structured map changes any research decisions.
6. Revise or abandon the platform hypothesis based on results.

## How to run the demonstrator

Open `index.html` in a browser. It is a static, local-first interface with illustrative records. It does not yet connect to PubMed, scientific datasets, an AI model, or a backend database.

## Founding principle

Build evidence before claims. Build a useful research instrument before calling it a platform. Build a defensible therapeutic program only after the biology and evidence justify it.
