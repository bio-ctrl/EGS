Backup and data handling

The application stores user-entered evidence and hypotheses in browser local storage on this device. Clearing browser data may erase that workspace. Export a JSON backup regularly. Imported files replace the current local workspace only after confirmation. No patient-identifiable information should be entered.

Engine boundaries

Automated imports create unreviewed metadata records. Abstract sentence extraction produces candidate passages only. The AI assistant can summarize supplied records but cannot verify source truth, establish novelty, assess clinical utility, or validate a therapeutic. Every generated statement must be checked against the original paper.
