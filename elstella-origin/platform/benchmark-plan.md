# ORIGIN ATLAS — BENCHMARK PLAN

**Status:** Proposed evaluation; no benchmark results exist.

## Research question

Does ORIGIN ATLAS improve the accuracy, reproducibility, efficiency or expert-rated usefulness of structured biomedical evidence mapping compared with a conventional literature-review workflow?

## Comparison

- **Control:** Conventional spreadsheet or document-based evidence extraction using the same protocol.
- **Intervention:** ORIGIN ATLAS using the same extraction schema and source set.
- **Unit of analysis:** Publication-level extraction and reviewer-level workflow outcomes.

## Study design

1. Select a manageable, pre-defined set of eligible publications.
2. Define extraction fields and scoring rules before comparing workflows.
3. Recruit qualified reviewers; disclose that this is an early prototype.
4. Randomize or counterbalance workflow order where feasible to reduce learning effects.
5. Have reviewers extract the same source set independently.
6. Use an adjudicator to resolve disagreements without erasing initial disagreement.
7. Compare outputs against a documented reference standard created by qualified reviewers.

## Outcomes

- Field-level extraction accuracy against adjudicated reference.
- Completeness of source provenance.
- Inter-reviewer agreement for key categorical fields.
- Time per paper and time per completed evidence map.
- Number of contradictions or context distinctions correctly identified.
- User-rated clarity and usefulness.
- Error rate, unsupported statements and false confidence.

## Predefined failure conditions

The platform fails this test if it does not improve any preselected outcome, introduces more unsupported claims, reduces traceability, or produces a misleading appearance of certainty. A null result is a valid result.

## Bias controls

Use identical source sets and extraction definitions. Avoid selecting only papers that make the tool look good. Report missing data, exclusions, deviations, reviewer expertise and uncertainty. Do not claim statistical superiority from a small convenience sample.

## Deliverable

A benchmark report with protocol, dataset description, anonymized reviewer-level results where consent permits, analysis code, limitations and a go / revise / stop decision.

## Current status

Not run. No performance advantage has been demonstrated.
